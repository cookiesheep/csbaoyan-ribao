The Press Room · 排印房

这份报纸是怎么印出来的

每一期日报都不是「把聊天记录丢给 AI」。在你看正文之前，每条消息要过五道工序—— 下面是印房里真实发生的事，每一期报头下的付印工单就是当天的加工记录。

  1. 01

    采集 INGEST

    每天清晨从本地聊天数据库读取目标群前一天的完整消息。纯本地文件读取，不创建登录会话、不碰协议。

  2. 02

    脱敏 REDACT

    所有发言者替换为 User_01 式代号；昵称、QQ 号、链接与敏感信息在进入模型前被移除，存档同样只保留代号。

  3. 03

    去噪 SIFT

    纯表情、应答语气词、同人连续刷屏由规则筛除——每期筛掉多少条、筛掉了什么类别，工单上印得清清楚楚。

  4. 04

    抽取 EXTRACT

    分块送入模型提炼要点。引用式抽取要求每条要点附带「原话 + 说话人 + 时间」——无据不成句，编不出来。

  5. 05

    编辑 EDIT

    汇总排版为今日概览 / 重要信息 / 经验观点 / 风险待核实四个版面，生成付印工单后发布。

正文里所有带朱红下划线的引文都逐字来自当日群聊——出自哪位发言者、几点说的，引用标记都可查。
G-Eval 评估
（可选开启）每期出报后由独立评审提示词打「忠实度 / 召回率」分，防止内容偏离原始讨论。展开付印工单可见。
事实核查
factcheck 把日报拆成原子声明逐条判定：有依据 / 相冲突 / 依据不足。任何一条失实都能被定位到句。
免责边界
群聊是个人经验与传闻，日报只做归纳、不做背书；时效与招生政策请以官方通知为准。
